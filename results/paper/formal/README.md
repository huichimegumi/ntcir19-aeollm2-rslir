# Table 9 formal result

`official_metrics.csv` transcribes the paper's organizer-returned reserved-set metrics for the official DeepSeek-v3.2 baseline, the RSLIR DeepSeek-v4-Flash OSODT submission, and their differences. The RSLIR weighted overall Spearman, Kendall, and Accuracy are 0.7071, 0.5592, and 0.7796.

The exact organizer-submitted prediction file and hidden gold labels are not included. These metrics cannot be locally recomputed from this repository. With authorized reports and rubrics, the method can be run using `configs/deepseek-v4-flash-paper.yaml` and the commands in the root README; that produces a new run.
